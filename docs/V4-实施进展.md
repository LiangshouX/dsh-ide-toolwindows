# V4 实施进展（工作区连续性、会话入口与聊天文件链接）

> 本轮按“先研究、再实施”的结论落地。范围：
> 1. 新会话（Ctrl+N）也显示 IDE 入口；
> 2. 同一工作区切会话不重建 IDE（v1）；
> 3. 聊天文件链接默认在 IDE 中打开，并可用设置切回 DSH 侧栏。

## 1. 已落地

### 新会话入口

- `conversation.hero.options` 增加 `ide-toolwindows` 图标；空白会话的 New Session 行可见。
- 原有 `conversation.session.header.utilities` 入口保留；非空白会话不重复显示。
- `sidebar.footer.action` 增加一个常驻图标（设置旁），在皮肤/窄窗口隐藏头部工具时仍可用，也覆盖无 session 的起始页展示。
- 三个入口共用一个 `requestOpen()`：右侧栏 store 尚未 adopt 时，用 `mounted`/`openTabs` 变化和短定时重试，最多约 1 秒。

### 工作区级工作台

- 客户端 store 从 `sessionId:tabId` 改为按工作区（`sessions.list.byId[id].cwd`）共享；没有 cwd 时回退到按 session。
- 同一时刻只渲染前台会话的 Workbench：后台会话的 `sidebar.right.pane.tab` body 保留挂载但返回 `null`，避免共享 store 时出现两套终端 socket / CodeMirror。
- 订阅 `ctx.sidebarRight.mounted`：离开的会话里 IDE 实际可见、且两会话 cwd 相同时，在到达的会话中自动 `openTab('ide-toolwindows')`。Ctrl+N 的空白会话同样适用。
- store 的 `init()` 现在带缓存，并以会话 cwd 作为首选工作区；`lastRoot` 只由可见 store 的持久化写入，避免后台 store 抢写。

### 聊天文件链接

- `sidebarRightTabs` 的 IDE 类型新增：
  - `patterns: ['dsh-resource://file/session/**', 'dsh-resource://file/absolute/**']`
  - `priority: 'extension'`
  - `canOpen` 读取设置并过滤 Office/PDF/压缩包/二进制
  - `title(address)` 对文件地址返回文件名
- 两个 pattern 比 `dsh-better-sidebar` 的 `dsh-resource://file/**` 更长，按注册表“匹配 pattern 长度”规则稳定优先。
- 文件资源 tab 由 `FileLinkBridge` 承接：解析地址、解析到会话工作区的绝对路径、打开预览 tab、展开 Project 树、定位 `#L24`，然后 `openTab(PANEL_ID, { replaceTab })` 替换成正常 IDE 页面 tab，避免每个链接都多一个完整 Workbench。
- 设置新增 `links.chatFiles`：`ide`（默认）/ `sidebar`；设置页“文件树”组提供下拉，切换即时生效（下一次点击）。
- 文件不在当前 IDE 项目根内时：若在 workspace 根内且没有 dirty tab，自动切到包含它的项目根；否则 toast 提示，不强行切换。

## 4. 已知限制（v1）

- 切会话时旧会话的 Workbench 组件会卸载重挂载：终端 PTY/xterm scrollback 重建，CodeMirror 撤销栈丢失；文件树、打开文件、Git 上下文由共享 store 保留。终端“断线重连 + scrollback 回放”留作后续里程碑。
- 自动重开只在“离开时 IDE 实际可见且同工作区”时触发；如果离开时右侧栏已折叠或 IDE tab 未激活，不会主动展开。
- 文件链接 claim 作用于所有 `sidebarRight.openResource` 文件地址（用户 @、助手 Markdown、工具结果/交付物），不只是聊天文本。
- Office/PDF/压缩包/二进制继续走 `dsh-better-sidebar` 或 DSH 自带预览。
- 完全未选择会话的初始页没有右侧栏，入口只在空白会话（Ctrl+N）起可用。
- 手动在 IDE 顶栏切换了工作区后，该工作区的 store 会保留手动选择；跨工作区会话仍按各自 cwd 取 store，属于已知边界。

- [ ] 带 `#L24` 的链接定位到行；`.pdf`/`.docx` 仍走侧栏预览。
- [ ] 设置 → IDE 工具窗口 → 聊天文件链接切到“侧栏”，再点文件链接回到 DSH 侧栏。
- [ ] 大仓库下切会话不再出现明显初始化等待。
